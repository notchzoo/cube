# v0.12.02 — Su-57 模型、飞行与 054 参考涂装

本版本在原有 PBR 场景中加入 Su-57 静态模型与固定翼飞行，并按上下视参考重画蓝灰/浅灰数码迷彩。

- 新增 glTF/GLB 加载器、法线补算、默认 Su-57 模型和加载器测试。
- 新增 120 Hz 固定翼动力学、起飞/巡航辅助、独立油门、姿态保持、过载限制、降落和重置。
- 新增十组控制面拆分、翼面检查模式、飞行 HUD 和第三人称跟随。
- 重画 3072×2048 上下表面、2048×1024 侧面贴图，包含白边红星、蓝绿色翼尖、面板线和 054 机号。
- 分开处理漆面、雷达罩、深色反光座舱、尾锥与带热变色环纹的金属喷口。
- 新增 `--jet-only` 材质检查模式；贴图启用 mipmap，保留缺失回退。

验证：MSVC Debug 编译、四项 CTest 通过；在 NVIDIA OpenGL 3.3 上实际加载 GLSL，检查默认场景与顶部、腹部、斜前方截图。

已知近似：迷彩为参考重绘，仍非逐像素照片复刻；座舱为不透明反光近似；飞行和控制面拆分为演示模型。

使用：按 `J` 进入喷气机飞行；`K` 检查控制面；使用 `--jet-only` 单独查看模型。构建方式见 README。

此版本保留 v0.12.01 及更早版本。Release 页下方的 Source code (zip/tar.gz) 包含源码、模型与贴图。
